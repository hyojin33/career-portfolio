## 3. 특수 문항 처리

### 3-1. 직업가치관 49번
- **매뉴얼**: 49=8,1,4 (쉼표 구분 3개)
- **구현**: ✓ 49-1, 49-2, 49-3 → 49=a,b,c

### 3-2. 진로성숙도 13번
- **공식 테스트센터**: "13=1,8 …객관식13번 문항은답2개(순서대로 1순위, 2순위)"
- **구현**: ✓ 13-1, 13-2 → 13=a,b
- **미구현**: "답변9(기타)은 주관식답변이필요" — 9번 선택 시 텍스트 입력?

### 3-3. 진로성숙도 36번 분기
- **문항**: 36번 '아니요' → 37~41 건너뛰고 42번으로
- **구현**: ✓ 37~41에 0 전송

### 3-4. 진로성숙도 46번 분기
- **문항**: 46번 '아니요' → 47~51 건너뛰고 52번으로
- **구현**: ✓ 47~51에 0 전송

**확인 필요**: 건너뛴 문항(37~41, 47~51)에 **0** 전송이 매뉴얼 규격과 일치하는지 확인해 주세요. ("-" 또는 다른 코드일 수 있음)

## 매뉴얼에서 확인 요청 사항

1. **진로성숙도 검사번호**: q=23 vs q=36 (매뉴얼 해당 페이지)
2. **건너뛴 문항 값**: 0 vs - vs 기타 (해당없음 코드)
3. **13번 기타(9번) 선택**: 주관식 텍스트 필수인지 여부

매뉴얼 해당 페이지 내용을 알려주시면 바로 수정 반영하겠습니다.
