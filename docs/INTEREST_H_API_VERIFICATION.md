# 직업흥미검사(H) API 매뉴얼 대조 검증

> 기준: openAPI이용매뉴얼_v4.0.pdf + 커리어넷 오픈API (진로심리검사 v2)

## v2 기본정보 (공식 문서)

| 구분 | URL |
|------|-----|
| 심리검사 목록 | `GET https://www.career.go.kr/inspct/openapi/v2/tests?apikey={키}` |
| 심리검사 문항 | `GET https://www.career.go.kr/inspct/openapi/v2/test?apikey={키}&q={번호}` |
| **심리검사 결과** | `POST https://www.career.go.kr/inspct/openapi/v2/report` |

### 결과 요청 (POST) 필드명
- `apikey`, `qno` (33/34), `startdtm`, `trgetse`, `gender`, `grade`, `school`, `answers`
- `answers`: `[{"no":"1","val":"1"}, {"no":"132","val":"-"}, ...]`

### 결과 응답 구조
```json
{
  "result": { "inspct": { "inspctseq": "...", "reporturl": "https://..." } },
  "success": "Y",
  "message": ""
}
```

### 현재 구현 vs 매뉴얼

| API번호 | 매뉴얼 예시 | 현재 구현 | 비고 |
|---------|-------------|----------|------|
| 132 | "-" (미결정) | 3-1 나의 희망 직업 | ✓ 동일 |
| 133 | "국제개발협력전문가" | 3-2 부모님이 원하는 | ✓ 동일 |
| 134 | "소방관" | 4-1-1 좋아하는 과목 1순위 | ⚠ 매뉴얼 예시는 단일 값 |
| 135 | "미술,과학" | 4-1-2 좋아하는 과목 2순위 | ⚠ 매뉴얼은 134+135를 "과목1,과목2" 하나로? |
| 136 | "음악,기타" | **5번 학교생활 만족도** | ❌ 매뉴얼은 과목(싫어하는) |
| 137 | "3" | 4-2-1 싫어하는 1순위 | ❌ 매뉴얼은 숫자(만족도?) |
| 138 | "4" | 4-2-2 싫어하는 2순위 | ❌ 매뉴얼은 숫자 |
| 139~146 | 4,4,4,3,4,3,4,5 | 6-1~6-9 (139~147) | ⚠ 매뉴얼은 139~146 (8개) |

## 3. 해석 차이

**매뉴얼 예시 해석 (추정):**
- 132, 133: 직업 (3-1, 3-2) ✓
- 134: ??? (단일 직업/과목)
- 135: "미술,과학" → 좋아하는 과목 1순위+2순위 (콤마 구분)
- 136: "음악,기타" → 싫어하는 과목 1순위+2순위 (콤마 구분)
- 137, 138: 학교생활 만족도 등 (숫자)
- 139~146: 과목별 성적 구간 (8과목?)

**현재 구현 (사용자 요구 반영):**
- 134, 135: 좋아하는 과목 1순위, 2순위 (별도)
- 136: 5번 학교생활 만족도 (사용자 지정)
- 137, 138: 싫어하는 과목 1순위, 2순위
- 139~147: 6-1~6-9 (9과목 성적 구간)

## 4. 수정 제안

### 4-1. 매뉴얼과 완전 일치시키려면
- 134, 135: "과목1,과목2" 하나의 문자열로 합쳐서 134에만 전송? (매뉴얼 예시가 불명확)
- 136, 137: "과목1,과목2" + 만족도 숫자 (순서 확인 필요)
- 139~146: 8과목만 (147 제거)

### 4-2. 고등학생(qno 34) 146문항일 때
- 139~146 = 8개 → 우리 6-1~6-8만?
- 6-9 기술가정(147)은 고등 146문항에 없을 수 있음

### 4-3. 확인 필요 사항
1. **qno 33 vs 34 문항 수**: 공식문서에서 33→146문항, 34→145문항으로 기재된 버전도 있음 (PDF와 상이). 요청 예시는 1~146 전송.
2. **134~138** 정확한 의미 (매뉴얼 예시만으로는 한계)
3. **139~146** 과목 수: 8개 (기술가정 147 제외)

### 결론
- **132, 133**: 직업 ✓
- **134~138**: 매뉴얼 일치 (134·135=4-1, 136=4-2 콤마합침, 137=5, 138=-)
- **139~146**: 8과목만 (147 기술가정 제거)
